# ระบบจัดการวิทยานิพนธ์ (Thesis Management System)

ระบบยื่น ติดตาม และลงนามเอกสารวิทยานิพนธ์ออนไลน์ สำหรับคณะวิศวกรรมศาสตร์ — รองรับการทำงานแบบหลายบทบาท (role-based)

**สถานะ: ใช้งานจริง (live)** — เชื่อมต่อฐานข้อมูล Supabase PostgreSQL จริง, อัปโหลดไฟล์ขึ้น Supabase
Storage (bucket ส่วนตัว ไม่เปิดสาธารณะ), ส่งอีเมลแจ้งเตือนจริงผ่าน SMTP ไม่ใช่ระบบจำลอง

## ฟีเจอร์หลัก

- เข้าสู่ระบบด้วยอีเมล/รหัสผ่าน + ลิงก์ลงชื่อเข้าใช้ครั้งเดียว (magic link) ที่ส่งมาในอีเมลแจ้งเตือนแต่ละขั้นตอน
- ขั้นตอนอนุมัติสองแบบ: **โครงร่างวิทยานิพนธ์ (PROPOSAL, 11 ขั้นตอน)** และ **สอบวิทยานิพนธ์ (THESIS_DEFENSE, 22 ขั้นตอน)**
- อัปโหลดเอกสารจริง (บ.วศ.1ก/1ข/1ค/1ง, บ.2/3/4, เล่มวิทยานิพนธ์ ฯลฯ) พร้อมระบบเก็บเวอร์ชันย้อนหลัง
- ลงนาม/อนุมัติ/ปฏิเสธ พร้อมแนบไฟล์ลงนาม — ปฏิเสธแล้วย้อนกลับหนึ่งขั้นตอนเสมอ นักศึกษาต้องแก้ไขแล้วยื่นใหม่
- คณะกรรมการสอบ/อาจารย์ที่ปรึกษาร่วมหลายท่าน ลงนามตามลำดับ (ผ่านเมื่อครบทุกท่าน)
- ติดตามสถานะแบบ timeline + แถบความคืบหน้า
- การแจ้งเตือน (bell in-app + อีเมล) ส่งถึงผู้รับผิดชอบขั้นตอนถัดไปโดยอัตโนมัติ รวมถึงอีเมลแจ้งฝ่ายการเงินและเตือนวันสอบ (cron รายวัน)
- **แดชบอร์ดแยกตามบทบาทผู้ดูแล**:
  - **Admin** (`/admin-dashboard`) — เจ้าของ workflow คำร้องทั้งหมดแต่เพียงผู้เดียว: ค้นหา/กรอง, กราฟการกระจายตามขั้นตอน, badge "ค้างนาน", แก้ไข/override ทุกขั้นตอน, จัดการบัญชี STUDENT/PROFESSOR/ADMIN
  - **Super Admin** (`/super-dashboard`) — ดูแลบัญชีผู้ใช้ระดับ SUPER_ADMIN/ADMIN เท่านั้น พร้อมตัวเลขภาพรวมทั้งระบบแบบอ่านอย่างเดียว (ไม่มีสิทธิ์เข้าถึงคำร้องใด ๆ)
- รองรับมือถือ + ฟอนต์ Sarabun (กลุ่มผู้ใช้รวมถึงอาจารย์อาวุโส เน้น UI ใหญ่ อ่านง่าย)

## Stack

- **Next.js 16** (App Router) + **React 19** + **TypeScript**
- **Tailwind CSS v4**
- **Prisma + Supabase PostgreSQL** (transaction pooler ใน production), **NextAuth v5**, **Supabase Storage** (private bucket + signed URL)
- **nodemailer** สำหรับอีเมลแจ้งเตือนขั้นตอน/การเงิน/เตือนสอบ

## คำสั่งที่ใช้บ่อย

```bash
npm run dev          # dev server (localhost:3000)
npm run build         # prisma generate && next build
npm run lint          # eslint
npm run db:seed       # tsx prisma/seed.ts
npm run db:studio     # prisma studio
```

ฐานข้อมูลจัดการด้วย `npx prisma db push` (ไม่มีโฟลเดอร์ `prisma/migrations/`) — ดูรายละเอียดใน `AGENTS.md`

## เอกสารประกอบ

- **`AGENTS.md`** — สเปกพฤติกรรมของแอปฉบับปัจจุบัน (workflow, บทบาท, กฎอีเมล, การอัปโหลด) ยึดตามนี้เป็นหลัก
- **`CLAUDE.md`** — แผนที่โครงสร้างโค้ดสำหรับผู้ช่วย AI
- **`HANDOFF.md`** — บันทึกการโอนย้ายเจ้าของระบบและตัวแปรสภาพแวดล้อม
- `docs/ARCHITECTURE.md` และ `docs/RECIPES.md` เป็นเอกสารเก่าจากเวอร์ชันก่อนเชื่อมฐานข้อมูลจริง **ล้าสมัยแล้ว ไม่ควรอ้างอิง**
